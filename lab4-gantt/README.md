# ЛР № 4. Диаграмма Ганта для БИ 3-2

Учебный календарный план создания АС программы лояльности. Стадии основаны на ГОСТ Р 59793-2021. Даты и длительности заданы для учебного проекта.

- `diag_ganta.puml` — редактируемый исходник.
- `diag_ganta.svg` — готовое изображение.

Для повторной сборки с PlantUML 1.2025.7 выполните:

```sh
java -Djava.awt.headless=true -jar /path/to/plantuml.jar -charset UTF-8 -tsvg diag_ganta.puml
```
